# A≡B — Personal Cloud Intelligence

An AI-powered personal cloud storage platform built with Next.js 15, 
Supabase, Groq Llama 4, and Voyage-3 embeddings.

## Features
- Natural language file management via AI chat
- Semantic search across all uploaded documents  
- Auto-classification into 35 categories
- Duplicate detection using vector embeddings
- PDF inline preview and multi-file synthesis

## Stack
Next.js 15 · TypeScript · Supabase · pgvector · Groq · Voyage AI · Tailwind CSS
