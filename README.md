# A≡B — Personal Cloud Intelligence

An AI-assisted personal cloud storage concept built with Next.js 15, Supabase, Groq, and Voyage embeddings.

## Documented capabilities
- Natural-language file-management interaction.
- Semantic search across uploaded documents.
- Automatic document classification into 35 categories.
- Duplicate detection using vector embeddings.
- PDF preview and multi-file synthesis.

## Technology
Next.js 15 · TypeScript · Supabase · pgvector · Groq · Voyage AI · Tailwind CSS

## Live demo
https://superior-cloud.vercel.app

## Architecture at a glance
- Next.js provides the web application.
- Supabase provides backend services and PostgreSQL with pgvector.
- Voyage embeddings support semantic document retrieval.
- Groq provides the language-model interface.

## Local development
Review the repository's package scripts and environment example before running locally. Configure provider credentials in local environment variables; do not commit secrets.
